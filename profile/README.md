🏗️ System Architecture
<p align="center">
  <img width="1280" height="485" alt="image" src="https://github.com/user-attachments/assets/17ae56bb-7dc7-44d4-b423-1a347899c7f7" />
</p>


<blockquote>
  <b>MSA(Microservices Architecture)</b> 기반으로 서비스별 독립 배포와 확장이 가능하도록 구성했습니다. (아래 설명은 초안이며, 확정 후 수정 필요)
</blockquote>


<details open>
<summary><b>1. 트래픽 제어 및 보안 (Traffic & Security)</b></summary>
<ul>
  <li><b>Cloudflare</b>: 도메인 연결 및 <b>HTTPS 보안 통신</b>을 담당합니다.</li>
  <li><b>API Gateway</b>: 모든 요청의 단일 진입점으로 <b>JWT 검증</b> 및 라우팅, 사용자 식별 헤더(X-User-Id/X-User-Role) 주입을 수행합니다.</li>
</ul>
</details>


<details>
<summary><b>2. 핵심 인프라 및 관리 (Infrastructure Management)</b></summary>
<ul>
  <li><b>Spring Cloud Config Server</b>: 중앙 저장소에서 환경 설정 정보를 통합 관리하고 배포합니다.</li>
  <li><b>Kubernetes</b>: 컨테이너 오케스트레이션 및 서비스 디스커버리(Spring Cloud Kubernetes)를 지원합니다.</li>
</ul>
</details>


<details>
<summary><b>3. 마이크로서비스 레이어 (Microservices Layer)</b></summary>
<table>
  <tr><th>Service</th><th>Description (초안)</th></tr>
  <tr><td><b>Front Server</b></td><td>Thymeleaf 기반 UI, Gateway를 통한 백엔드 통신 수행</td></tr>
  <tr><td><b>Auth(User) Server</b></td><td>회원 가입/로그인/인증, 문의(Inquiry) 관리</td></tr>
  <tr><td><b>Cultivation Server</b></td><td>재배지(Cultivation) 생성/관리, 멤버 및 역할(Owner/Manager/Member) 관리, 센서·환경설정, 수확 기록</td></tr>
  <tr><td><b>Rule Engine Server</b></td><td>센서 값 기반 임계값 판단 및 자동 제어 로직 수행</td></tr>
  <tr><td><b>AI Server</b></td><td>생육 분석, 일일 피드백, 인사이트, 챗봇</td></tr>
  <tr><td><b>Embedding Server</b></td><td>버섯 가이드 등 참조 데이터 임베딩 처리</td></tr>
  <tr><td><b>Notification Server</b></td><td>이벤트 기반 알림 발행 및 구독 채널 관리</td></tr>
  <tr><td><b>Data Generator</b></td><td>센서 데이터 시뮬레이션/생성</td></tr>
</table>
</details>


<details>
<summary><b>4. 데이터 저장 및 메시징 (Persistence & Messaging)</b></summary>
<ul>
  <li><b>PostgreSQL</b>: 서비스별 스키마로 분리된 영속성 데이터 저장소입니다.</li>
  <li><b>Redis</b>: 캐싱 및 세션/토큰 관리를 지원합니다.</li>
  <li><b>InfluxDB</b>: 센서 시계열 데이터 저장 및 집계에 사용합니다.</li>
  <li><b>RabbitMQ</b>: 서비스 간 결합도를 낮추는 <b>비동기 이벤트 메시징</b> 역할을 합니다.</li>
  <li><b>MinIO</b>: 재배 사진 등 파일 오브젝트 스토리지로 사용합니다.</li>
  <li><b>pgvector</b>: AI 챗봇/인사이트를 위한 벡터 검색 저장소입니다.</li>
</ul>
</details>
🚀 CI/CD Pipeline
<p align="center">
  <img width="1996" height="1041" alt="image" src="https://github.com/user-attachments/assets/6b987935-fc66-4a91-9807-4a4fc876db34" />
</p>


<blockquote>
  GitHub Actions 기반으로 <b>AI 코드 리뷰(CodeRabbit)</b>와 <b>정적 분석(SonarQube)</b>이 포함된 자동화 파이프라인을 운영합니다.
</blockquote>


1. 지속적 통합 (Continuous Integration)
* PR Check: develop, main 브랜치 대상 PR 시 의존성 트리 검사, 테스트(PostgreSQL/RabbitMQ/InfluxDB/MinIO 컨테이너 기반), Docker 빌드 검증을 자동 수행.
* CodeRabbit (AI Review): AI를 통한 로직 분석 및 자동 코드 리뷰로 품질 사전 점검.
* SonarQube (Static Analysis): JaCoCo 커버리지 연동, 버그/취약점/코드 스멜 탐지.

2. 품질 게이트 및 배포 (Quality Gate & CD)
* Quality Gate: 커버리지 기준(JaCoCo threshold) 미달 시 배포 중단.
* Automated Deployment: main 브랜치 반영 시 GHCR(GitHub Container Registry)로 이미지 빌드/푸시 후 Kubernetes 환경에 자동 배포.
* Rollback: 배포 실패 시뮬레이션 및 롤백 검증 워크플로우 포함.

✨ 주요 기능 (Key Features)
<details open>
<summary><b>1. 재배지 관리 (Cultivation)</b></summary>
<br>
<ul>
  <li><b>재배지 생성/조회/이력/종료/삭제</b>: 버섯 종류 및 센서 디바이스를 지정해 재배지를 생성하고, 소프트 삭제로 이력을 보존합니다.</li>
  <li><b>역할 기반 멤버 관리(RBAC)</b>: 멤버 추가/조회/역할 변경/삭제, 소유권(Owner) 위임을 지원합니다.</li>
  <li><b>수확 관리</b>: 수확 등록/조회, AI 분석 결과를 반영한 상품 등급(Product Score) 갱신을 지원합니다.</li>
  <li><b>수확 모드 전환</b>: 재배 → 수확 전환 시 해당 단계 임계값을 자동으로 재적용합니다.</li>
  <li><b>재배 사진</b>: 사진 업로드/조회/삭제(MinIO 저장, presigned URL 발급)를 지원합니다.</li>
</ul>
</details>


<details>
<summary><b>2. 센서 및 환경 자동 제어 (Sensor & Rule Engine)</b></summary>
<br>
<ul>
  <li><b>센서 데이터 수집</b>: MQTT로 수신한 센서 데이터를 InfluxDB에 시계열로 저장하고, 추이·평균 조회를 지원합니다.</li>
  <li><b>임계값 기반 자동 제어</b>: 임계값 초과 여부를 판정해 가상 액추에이터를 자동으로 제어합니다.</li>
  <li><b>환경 준수율 계산</b>: 설정한 환경 기준을 얼마나 지켰는지 기간별/일자별로 계산해 제공합니다.</li>
  <li><b>알림 쿨다운</b>: 동일한 이상 알림이 반복 발송되지 않도록 제어합니다.</li>
</ul>
</details>


<details>
<summary><b>3. AI 생육 분석 및 챗봇 (AI)</b></summary>
<br>
<ul>
  <li><b>일일 피드백</b>: 전일 데이터를 분석해 생육 피드백을 자동 생성합니다(아웃박스 패턴 기반 안전한 이벤트 발행/재처리 포함).</li>
  <li><b>인사이트</b>: 과거 데이터 기반 인사이트 후보를 조회하고 상세 내용을 제공합니다.</li>
  <li><b>챗봇</b>: 웹에서 재배 관련 질의응답을 실시간으로 제공하고, 재배지 단위로 대화 이력을 저장/조회합니다.</li>
  <li><b>버섯 가이드</b>: 참조 데이터를 벡터로 적재해 생육 가이드를 생성·제공합니다.</li>
  <li><b>Vision 연동</b>: 재배 사진을 Vision 분석 서비스로 전달해 결과를 중계합니다.</li>
</ul>
</details>


<details>
<summary><b>4. 회원 및 인증 (Membership & Auth)</b></summary>
<br>
<ul>
  <li><b>회원 가입 및 관리</b>: 이메일 인증, 소셜(OAuth2 Google) 로그인, 휴면 계정 해제, 탈퇴(soft delete)를 지원합니다.</li>
  <li><b>JWT 기반 인증</b>: Gateway에서 토큰을 검증하고 사용자 식별 정보를 하위 서비스로 전달합니다. 로그아웃 시 Access Token을 블랙리스트 처리합니다.</li>
  <li><b>문의(Inquiry)</b>: 사용자 문의 등록 및 관리자 응답(사진 첨부 포함) 관리를 지원합니다.</li>
</ul>
</details>


<details>
<summary><b>5. 알림 (Notification)</b></summary>
<br>
<ul>
  <li><b>이벤트 기반 알림</b>: AI/Cultivation/Rule Engine/User 도메인 이벤트를 구독해 Discord/Telegram으로 알림을 발송합니다.</li>
  <li><b>발송 안정성</b>: 발송 실패 재시도, Dead Letter 처리, 발송 대기 건 복구 스케줄러를 갖추고 있습니다.</li>
  <li><b>구독 채널 관리</b>: 사용자가 알림 엔드포인트와 구독 유형을 등록/관리합니다.</li>
  <li><b>알림 통계</b>: 일별/기간별 알림 발송 통계를 제공합니다.</li>
</ul>
</details>
